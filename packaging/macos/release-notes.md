## Install

1. Download the `.dmg` file below. It is for Apple Silicon Macs.
2. Open it and drag Mars-Macos to Applications.
3. The app has no Apple Developer ID yet, so macOS blocks the first start. Open Mars-Macos once, then go to System Settings > Privacy & Security and click **Open Anyway**.

After this, the app can update itself. See Help > Check for Updates.

The app has its own Java. You do not need to install Java.
